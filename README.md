# שירון

עורך דפי אקורדים בעברית. אקורדים באנגלית מעל מילים בעברית, בלי שהשורה מתהפכת.

**כתובת חיה:** https://liav-chanoch.github.io/chord-sheet/

קובץ אחד, `index.html`, עם CSS ו-JavaScript פנימיים. בלי בנייה, בלי תלויות, בלי שרת.
השירים נשמרים כקבצי טקסט רגילים בתיקייה `songs/`.

---

## מה הכלי עושה

- כתיבה בפורמט ChordPro, ותצוגה חיה של דף האקורדים לצידה
- טרנספוזיציה בחצאי טונים, עם מעבר בין דיאזים לבמולים
- שליטה בגודל הטקסט
- המרה אוטומטית מהפורמט הישן של שורת אקורדים מעל שורת מילים
- הדפסה או ייצוא ל-PDF ישירות מהדפדפן
- העתקה לוורד או לגוגל דוקס, מיושרת נכון בעזרת טבלאות
- ספריית שירים שנשמרת במאגר עצמו
- טיוטות מקומיות בדפדפן, כרשת ביטחון

---

## תחביר

### אקורד מעל מילה

אקורד נכתב בסוגריים מרובעים ממש לפני ההברה שבה הוא מתחלף:

```
[Am]עוד יבוא שלום [F]עלינו
[C]ועל [G]כולם
```

האקורד יופיע מעל ההברה שאחריו. אפשר לשים אקורד גם באמצע מילה:

```
[C]ועל כל הע[G]ולם
```

### כותרת מקטע

שורה שמתחילה בסולמית:

```
# פזמון
```

### שורה ריקה

שורה ריקה בקובץ מייצרת רווח בדף.

### שורה אינסטרומנטלית

שורה שיש בה רק אקורדים, בלי מילים ובלי סוגריים מרובעים, נכתבת כשורה אחת:

```
E, C, F#, A x4
```

היא תוצג משמאל לימין, בפונט של האקורדים, ותעבור טרנספוזיציה יחד עם השאר.

## איך השמירה עובדת

השירים הם קבצי טקסט במאגר. אין בסיס נתונים ואין שרת. לכן השמירה עוברת דרך גיטהאב עצמו.

### דרך עורך הקבצים של גיטהאב, בלי טוקן

לחיצה על **שמירה** פותחת דיאלוג עם שני שלבים:

1. **קובץ השיר.** נפתחת לשונית חדשה בעורך של גיטהאב, `songs/<slug>.txt`, עם התוכן כבר בפנים.
   נשאר ללחוץ על **Commit changes**.
2. **קובץ הרשימה.** אותו דבר עבור `songs/manifest.json`, כשהרשומה החדשה כבר משולבת במערך הקיים.

אם התוכן ארוך מכדי להיכנס לכתובת אינטרנט, יש **העתקת תוכן הקובץ** ו**הורדה כקובץ txt**,
ואפשר להדביק ידנית בעורך של גיטהאב.

### עם טוקן, ישירות דרך ה-API

בפאנל **הגדרות** אפשר להדביק fine-grained personal access token של גיטהאב, מוגבל למאגר הזה בלבד
ועם הרשאת `contents:write`. כשיש טוקן, כפתור השמירה כותב ישירות את קובץ השיר ואת קובץ הרשימה,
בלי לפתוח לשוניות.

הטוקן נשמר ב-localStorage של הדפדפן בלבד. הוא לא נכתב לשום קובץ במאגר, לא מופיע בשום כתובת,
ולא נשלח לשום מקום מלבד `api.github.com`. אפשר להסיר אותו באותו פאנל.

השמירה עם הטוקן היא לגמרי אופציונלית. בלי טוקן הכל עובד דרך העורך של גיטהאב.

## עריכה ישירה של הקבצים

השירים הם טקסט רגיל ב-UTF-8. אפשר לערוך אותם ישירות עם git, עם כל עורך טקסט, או עם Claude Code:

```bash
git clone https://github.com/liav-chanoch/chord-sheet.git
cd chord-sheet
$EDITOR songs/shalom-aleinu.txt
```

אחרי הוספה או שינוי של קובץ שיר, יש לעדכן גם את `songs/manifest.json`:

```json
[
  {
    "id": "s1a2b3c4",
    "slug": "shalom-aleinu",
    "title": "עוד יבוא שלום עלינו",
    "artist": "מוסה אלעפיה",
    "updated": "2026-09-10"
  }
]
```

| שדה | משמעות |
| --- | --- |
| `id` | מזהה יציב לשיר. לא משתנה גם אם השם משתנה. משמש גם למפתח הטיוטה המקומית. |
| `slug` | שם הקובץ בלי הסיומת. אותיות קטנות באנגלית, ספרות ומקפים בלבד. |
| `title` | שם השיר, כפי שיוצג ברשימה ובדף. |
| `artist` | מילים ולחן. |
| `updated` | תאריך בפורמט `YYYY-MM-DD`. הרשימה ממוינת לפיו, מהחדש לישן. |

לאחר `git push` הכתובת החיה מתעדכנת תוך דקה או שתיים. האפליקציה מוסיפה `?v=<timestamp>`
לכל בקשה, כדי שגיטהאב פייג'ס לא יגיש גרסה ישנה מהמטמון.

## ייצוא וייבוא

**ייצוא ספרייה** מוריד קובץ JSON אחד עם כל השירים והתוכן שלהם.
**ייבוא ספרייה** קורא קובץ כזה חזרה וממזג לפי `id`, בלי למחוק דבר.
שירים שיובאו ועדיין לא נשמרו למאגר מסומנים ברשימה בתגית **מקומי**.

---

## טיוטות מקומיות

בזמן הכתיבה התוכן נשמר ב-localStorage תחת `chordsheet:draft:<id>`, כשמונה מאיות שנייה
אחרי שמפסיקים להקליד. זו רשת ביטחון בלבד, לא הספרייה.
אם קיימת טיוטה ששונה מהקובץ שבמאגר, מופיעה שורה קטנה עם האפשרות לשחזר או למחוק אותה.
כשהתוכן חוזר להיות זהה לקובץ, הטיוטה נמחקת מעצמה.

---

## עבודה מקומית

אפשר לפתוח את `index.html` ישירות בדפדפן. במצב הזה טעינת הרשימה נכשלת בשקט,
הספרייה מוצגת ריקה, וכל שאר הכלי עובד. לספרייה מלאה מקומית:

```bash
python3 -m http.server 8000
```

ואז http://localhost:8000
